## 💬 Customize Your Website

To change colors, edit `/resort_system/static/style.css`:

```css
:root {
    --primary-brown: #A85C3C;    /* Change this */
    --primary-orange: #C47D5C;   /* Or this */
    --dark-brown: #6B4423;       /* Or this */
    /* etc... */
}
```

All colors throughout the site will automatically update!
